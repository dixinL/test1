# 市场环境指标说明

> 定位：**环境辅助层**——只展示、只积累样本，不参与行业 4 档判定与三态判定。
> 数据由 `general-data/refresh.py` 的 erp / env 刷新步骤入库，展示由
> `sw2-market-env/env_report.py`（环境日报）与日报的 ERP 行承担。
> 待样本积累充分后，可按回测择优流程（参考 test2 辅助信号步骤 4 的备忘模式）
> 评估是否升级为正式条件。

## 一、数据链路与存储

| 环节 | 位置 |
|------|------|
| 抓取/入库 | `general-data/swfetch.py`（`fetch_and_store_erp` / `fetch_and_store_env`） |
| 现算入库 | `general-data/refresh.py`（`refresh_vol20` / `refresh_mainline`，从库内数据重算，不联网） |
| 存储 | `general-data/sw.db`：`erp` 表 + `env_daily` 窄表（indicator, trade_date 主键）+ `index_daily`（扩列 volume/amount） |
| 数据窗口 | **5 年滚动**（`swfetch.ENV_RETAIN_YEARS`），抓取层入库前过滤窗口外旧行；`refresh.py --purge`（CI 每年 5 月 1 日自动）定期剪裁 |
| 展示 | 本目录 `env_report.py` → `report/market_env_{date}.md`；日报 ERP 行（`sw2-daily-report/action_report.py`）→ combined 注入 |

`env_daily` 为窄表设计（每行一个指标一个日期），后续新增指标（涨跌家数、
人民币汇率等）直接扩 indicator 值即可，无需改表。

## 二、指标清单

### 1. ERP 估值环境（erp 表，月度采样）

- **含义**：剥离利率环境的估值锚。ERP（股权风险溢价）= 盈利收益率 EY − 10Y 国债收益率。ERP 高分位 = 股相对债便宜。
- **计算**：EY = 100 / PE_TTM；ERP = EY − 10Y 国债。分位 = 序列内 erp <= 当前值占比。
- **数据源**：沪深300 PE-TTM（乐咕 `stock_index_pe_lg`，月末点+当月滚动点）；10Y 国债（`bond_zh_us_rate` 中国列）。
- **单位**：%。**展示位置**：日报"一、市场总体状态"ERP 行（combined 同步注入）+ 本工具"一、估值与利率"。

### 2. us10y —— 10Y 美债收益率（env_daily，日频）

- **含义**：全球定价锚。与人民币汇率共振抬升 = 全球流动性收紧信号；快速下行 = 风险偏好回暖。
- **数据源**：`bond_zh_us_rate` 美国国债收益率10年列（历史可回溯至 1990 年，入库按 5 年窗口过滤）。
- **单位**：%。**解读**：绝对水平 + 分位；关注方向变化而非点位。

### 3. dr007 —— DR007 定盘利率（env_daily，日频）

- **含义**：存款类机构 7 天质押式回购定盘利率（FDR007），银行间短端流动性核心温度计。利率低位=资金宽松，快速上行=边际收紧。
- **计算**：直接取 FDR007 定盘值，不加工。
- **数据源**：中国货币网 `repo_rate_hist`（FDR007 列，2017-05 起有数据；按年分块拉取，30 自然日滚动窗口 upsert 防漏日）。
- **单位**：%。**解读**：与 7 天逆回购政策利率的利差更有意义，后续可加算。

### 4. turnover —— 两市成交额（env_daily，日频）

- **含义**：全市场活跃度与情绪温度。放量上行为增量资金入场，缩量为观望/出清。
- **计算**：上证综指(sh000001)成交额 + 深证综指(sz399106)成交额，换算亿元。综指覆盖全市场（成指只含成分股，故不用 399001）。
- **数据源**：东财 kline（`f57` 成交额），同步入 `index_daily.amount` 列。
- **单位**：亿元。**解读**：分位（5 年窗口）看活跃度相对位置；配合趋势方向使用。

### 5. vol20 —— 20 日已实现波动率（env_daily，日频，现算）

- **含义**：市场波动水平。低波动=趋势友好期，波动率骤升常伴随趋势转折。（QVIX 指数接口已停更，故自算替代。）
- **计算**：上证综指日收益率（%）近 20 日样本标准差 × √250 年化，基于 `index_daily` 收盘序列现算。
- **单位**：%（年化）。

### 6. high20 / low20 —— 创 20 日新高/新低家数（env_daily，日频）

- **含义**：市场广度。新高家数远超新低=强市；新低压倒新高=普跌出清期。净额（新高−新低）符号为强弱快判。
- **计算**：直接取全 A 统计值（原需求为 5 日口径，接口无 5 日只有 20/60/120，取 20 日——更平滑、噪声更小）。
- **数据源**：乐咕 `stock_a_high_low_statistics(symbol='all')`，接口自带约 2 年历史。
- **单位**：家。**解读**：绝对值与净额，不参与分位。

### 7. mainline_top5 / mainline_disp —— 主线强度与离散度（env_daily，日频，现算）

- **含义**：主线结构是否清晰。结构性行情离散度大（少数行业领涨）；普涨/普跌离散度小。
- **计算**（基于 `price` 表全部行业，近 20 日涨幅）：
  - `mainline_top5`：涨幅 Top5 行业均值（主线强度）；
  - `mainline_disp`：Top5 均值 − 全体行业中位数（离散度）。
- **单位**：%。**档位**（暂定，供展示）：
  - Top5 均值 < 0 → 普跌市，无主线
  - 离散度 ≥ 8% → 主线清晰
  - 3% ≤ 离散度 < 8% → 主线一般
  - < 3% → 普涨/均衡，无明显主线

## 三、分位口径（统一）

- **定义**：序列内 value <= 当前值的占比（ERP 为 erp <= 当前值）。
- **窗口**：库内全量序列 = 5 年滚动窗口（抓取层过滤 + purge 剪裁双保险）。
- **无未来函数**：回放模式（`--date`）下序列截断至基准日再算分位。
- **样本不足**（<2 个点）显示"样本不足"替代分位。

## 四、待扩展（第三批，仅实时接口，需向前积累）

- **涨跌家数**：乐咕实时快照 `stock_market_activity_legu`（无历史，逐日落库）。
- **人民币汇率**：历史源待定（东财实时值可得；USDCNH push2his 通道未验证）。

## 五、使用原则

1. 环境指标用于**辅助解读**大盘九场景与行业判定，不改变任何判定逻辑。
2. 关注**方向与极值**（利率快速上行、波动率骤升、广度净额翻负），而非单日点位。
3. 样本积累约 3 个月后分位展示趋于稳定；在此之前参考绝对值与趋势。
